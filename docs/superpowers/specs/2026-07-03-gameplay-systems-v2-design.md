# AI 创业模拟器：玩法系统 V2 设计

## 目标

本轮迭代把游戏从“静态动作加减数值”升级为“开局差异 + 效率公式 + 多层季度决策 + 可解释榜单/结局”的模拟系统。核心要求是数据自洽：玩家做每一个选择时，都能看到它为什么影响现金、Runway、ARR、模型能力、团队、合规、创始人健康和最终结局。

本轮仍不引入后端、不联网、不做大型 3D。所有模拟必须 deterministic，便于测试、存档和复现美股 IPO 路线。

## 开局系统

开局由三层叠加：

1. 创业身份：影响创始人属性和初始公司指标。
2. 创业赛道：影响创始人属性、初始指标、事件倾向和排行榜赛道权重。
3. 属性预设：不再只是替换滑杆，而是作为创始人训练倾向，影响初始属性和少量指标。

属性点不再固定 24。每个身份/赛道/预设都有自己的总点数和短板：

- 前大模型研究员：技术高、伦理高、模型能力高；销售/管理弱。
- 大厂产品经理：产品、管理、PMF 高；模型不顶尖。
- 连续创业者：融资、销售、市场热度高；股权少、合规风险略高。
- 海外博士：技术、全球化高；国内商业化慢。
- 开源维护者：技术、声誉高；MRR 起步慢。
- 资源型创始人：现金、融资、人脉高；声誉和伦理风险更高。

属性可以在游戏中提升。首版提升方式：

- 创始人学习：提升技术/管理/销售之一，消耗现金和健康。
- 导师复盘：提升融资/管理，降低董事会压力。
- 度假恢复：提升体力，恢复创始人健康，但季度产出减少。
- 闭关科研：提升技术和模型能力，增加健康消耗。

## 指标与效率公式

每个动作不再只使用固定 `effects`。引入 `ActionDefinition`：

- `baseEffects`：基础收益/成本。
- `costs`：现金、健康、Runway、股权等成本。
- `efficiency`：由属性和指标计算的倍率。
- `riskEffects`：高风险情况下附加的负面影响。
- `visibleSummary`：UI 显示预计变化。

效率原则：

- 技术影响模型训练、科研、技术债治理。
- 销售影响 MRR/ARR 增长、客户事件收益。
- 融资影响融资金额、估值、稀释比例。
- 管理影响招聘、稳住团队、员工操作效果。
- 伦理影响合规风险、灰色动作翻车概率。
- 体力影响额外行动、创始人健康损耗。
- 声量影响公关、市场热度、融资叙事。
- 运气影响随机事件的正负偏移，但幅度小于核心能力。

指标也影响效率：

- PMF 提高销售转化和留存。
- 模型能力提高科研声誉和模型榜排名。
- 产品质量提高 PMF、ARR 留存和企业事件收益。
- 算力供给提高模型训练效率。
- 算力成本降低 Gross Margin 和训练性价比。
- 声誉提高融资、招聘、排行榜曝光。
- 士气影响员工效率、离职风险和产品推进。
- 合规风险提高监管事件和坏结局概率。
- 全球化准备影响海外 ARR、美股 IPO、全球榜。
- 董事会压力影响融资条款、创始人被替换风险。
- 创始人健康影响额外行动、坏事件和健康结局。

UI 中每个动作卡必须显示“预计变化”，例如：

`模型能力 +6~9，现金 -50 万，算力成本 +4，健康 -4`

预计值由当前 `GameState` 计算，不在 UI 中手写。

## 季度行动结构

每季度分为四层：

1. 公司动作：默认 2 次。
2. 额外公司动作：可花现金和创始人健康购买 1 次。
3. 创始人动作：每季度 1 次，可选择跳过。
4. 员工动作：每个员工每季度可选择 0 或 1 次操作。

员工动作不再是全公司必选。每名员工单独操作：

- 加薪留人：现金下降，目标员工忠诚上升，离职风险下降。
- 期权刷新：创始人股权下降，忠诚上升，董事会压力略升。
- PUA 激励：短期产出上升，疲劳和离职风险上升。
- 放假修整：疲劳下降，短期产出轻微下降。
- 晋升授权：能力和忠诚上升，薪资上升。
- 裁员止血：现金/Runway 改善，士气和声誉下降。
- 跳过：没有直接成本，但疲劳自然累积，低忠诚员工更危险。

## 新增动作

公司动作扩展为多类别。

科研类：

- 论文攻坚：模型能力和声誉上升，现金/健康消耗。
- 合成数据飞轮：模型能力上升，合规风险上升。
- 推理优化：Gross Margin 上升，模型能力小幅下降或技术债上升。
- 开源核心组件：声誉上升，商业化速度下降，可能触发开源事件。

商业类：

- 企业深耕：ARR 上升，技术债上升。
- 渠道合作：ARR 和全球化上升，Gross Margin 下降。
- 提价：Gross Margin 上升，PMF/客户事件风险上升。

创始人类：

- 度假：健康和体力恢复，市场热度下降。
- 学习管理：管理属性上升，现金下降。
- 路演叙事：融资/声量上升，健康下降。
- 闭关科研：技术/模型能力上升，健康下降。

剑走偏锋类：

- 学术造假：模型能力/声誉短期大幅上升，合规风险和隐藏翻车事件上升。
- 刷榜营销：市场热度/声誉上升，声誉崩塌事件概率上升。
- 灰色数据集：模型能力上升，合规风险显著上升。
- 夸大 ARR：融资评分上升，收入确认风险和 CFO 事件上升。

高风险动作必须收益大、风险也大，并且能解锁隐藏成就或坏结局。

## 随机事件

玩家反馈“玩不到事件”，因此事件系统需要显著提高触达率。

规则：

- 每季度最多 1 个事件。
- 基础事件概率 60%。
- 市场热度 >= 70：+15%。
- 合规风险 >= 50：+15%。
- 员工平均疲劳 >= 60：+15%。
- 董事会压力 >= 60：+10%。
- 最近一季度刚触发事件：下一季度 -20%，避免连续轰炸。

实现方式：

- `shouldTriggerEvent(game)` deterministic，基于 seed/year/quarter。
- `pickNextEvent(game)` 只在触发时返回事件。
- resolved 事件仍不重复。
- 高风险动作会把相关事件提前加入候选。

## 成就系统

现有成就偏少。扩充到至少 45 个，其中隐藏成就至少 15 个。

普通成就示例：

- 第一张发票
- 千万 ARR
- A 轮毕业
- 海外首单
- 毛利转正
- 模型榜入围
- 商业化榜入围
- 团队 10 人
- 全球化 50

隐藏成就示例：

- 学术造假翻车
- 榜外逆袭
- 创始人被职业 CEO 替换
- 员工集体跳槽
- 开源背刺幸存者
- 纸面富豪
- 美股敲钟
- 港股敲钟
- 监管铁拳
- 灰色数据集幽灵
- ARR 注水
- 睡在办公室的一年
- 现金流自举冠军
- 被巨头低价收购
- 产品还没做完先成网红

最高等级/隐藏成就只显示名称，条件显示 `???`。

## 排行榜

排行榜改为多榜单：

1. 综合榜：模型、商业化、全球化、声誉、PMF 综合。
2. 模型能力榜：模型能力、算力供给、科研声誉。
3. 商业化榜：ARR、MRR、Gross Margin、PMF。
4. 全球化榜：全球化准备、海外 ARR、合规风险。

玩家起步不默认第 9。玩家在榜外时显示：

`榜外 / 距 Top 50 还差 18 分`

门槛：

- 综合分 >= 45：进入 Top 50。
- 综合分 >= 60：进入 Top 20。
- 综合分 >= 75：进入 Top 9。

进入 Top 9 后与 DeepDuck、OpenMind、BytePlanet 等公司同榜排序。

排行榜公司可点击查看详情：

- 公司名
- 原型影射说明
- 优势
- 弱点
- 排名规则贡献
- 与玩家关系

## 指标解释

所有关键指标要在 UI 上可解释。鼠标移动到指标标题时显示 `title`，并且在指标区域提供可访问说明。

必须解释：

- Runway：现金还能支撑公司运行的月份。
- ARR：年度经常性收入。
- MRR：月度经常性收入。
- PMF：产品市场匹配度。
- Gross Margin：毛利率。
- 模型能力：模型效果、Benchmark、研发壁垒。
- 全球化准备：海外销售、合规、本地化能力。
- 董事会压力：投资人和治理压力。

## 美股 IPO 范例 OnePage

新增 `docs/US_IPO_ONEPAGE.md`，写一条可复现路线。

内容包括：

- 推荐开局：海外博士/连续创业者 + 企业知识库或 AI Coding。
- 前 2 年：PMF、产品质量、第一笔 ARR。
- 3-5 年：A/B 轮、CFO、合规、Gross Margin。
- 6-8 年：全球化、美国客户、ARR 过 1.5 亿。
- 关键指标门槛：ARR >= 1.5 亿、全球化准备 >= 75、合规风险 <= 35、创始人健康 > 40。
- 每年建议动作和风险规避。

OnePage 是文档，不要求游戏自动脚本。

## 测试策略

新增/更新测试：

- 开局身份、赛道、属性预设都会改变属性和初始指标。
- 属性点可以不等于 24，且游戏中可以提升。
- 动作预览显示当前状态下的预计变化。
- 动作效率受属性和指标影响。
- 可购买额外公司动作，且现金/健康被扣除。
- 创始人动作影响属性和健康。
- 员工动作按员工逐个应用，不再全公司必选。
- 事件触发概率比旧版更高，但每季度最多一个。
- 成就数量和隐藏成就数量达标。
- 榜外/Top 50/Top 20/Top 9 门槛正确。
- 点击排行榜公司可查看详情。
- OnePage 存在且包含美股 IPO 门槛。

- 不做后端。
- 不做 App Store。
- 不做复杂 AI 对手行动树。
