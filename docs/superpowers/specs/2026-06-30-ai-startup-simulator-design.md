# AI 创业模拟器：从 Demo 到敲钟，或从敲钟到进厂

## 1. 设计目标

这是一个黑色幽默向的 AI 创业经营模拟器。玩家扮演一名中国 AI 创业者，从 2026 年开始创业，在 12 年内经历融资、招人、训练模型、做产品、拿客户、出海、巨头围剿、监管、上市或清算。

游戏不是严肃商业课程，但底层数据要自洽。每个段子、随机事件、成就和结局都由明确条件触发，让玩家感觉自己不是在看随机文案，而是在和现金流、算力、组织、合规、市场窗口做动态博弈。

核心体验：

- 早期：靠 Demo、关系、PPT 和信念融资。
- 中期：在 ARR、PMF、算力成本和组织失控之间挣扎。
- 后期：选择 IPO、并购、现金流公司、全球扩张、开源路线或体面失败。
- 全程：黑色幽默，但每个结果都能从数据上解释。

## 2. 玩法边界

产品形态做本地 Web App，不联网、不接真实支付、不调用外部 AI。所有数据、事件、NPC 和结局都在本地生成。

完整设计容量：

- 12 年生命周期，每年 4 个季度。
- 初始加点、创始人出身、赛道选择。
- 中国起步，可扩张到全球市场。
- 16 个公司/巨头势力。
- 30 个投资人/客户/战略方 NPC。
- 14 类融资方式。
- 14 类员工角色。
- 招聘、升职、加薪、期权、裁员、反挖、跳槽。
- 160 个事件模板。
- 80 个成就。
- 36 个结局。
- 本地存档、年度报告、最终复盘。

首个可玩切片：

- 保留完整 12 年生命周期和核心数值。
- 先实现 40 个事件、20 个成就、12 个结局。
- 先实现 12 个投资人 NPC、8 个巨头势力、8 类员工角色。
- 先实现中国起步、东南亚/中东/欧洲/美国 4 条出海路径。
- 系统接口按完整容量设计，内容可以后续扩写。

暂不做：

- 多人联机。
- 真实公司 Logo 或商标。
- 真实人物姓名。
- 复杂会计报表。
- 实时战斗或高频点击玩法。

## 3. 世界观和影射规则

游戏发生在一个近未来但明显影射现实的 AI 商业世界。公司、基金和人物全部架空化。

影射原则：

- 可以让玩家看出灵感来源。
- 不使用真实公司 Logo、商标口号、真实高管姓名。
- 不直接复刻真实负面事件。
- 所有讽刺都指向行业现象，而不是特定真实个人。

## 4. 核心循环

游戏时间以季度推进。每年 4 个季度，每季度玩家选择 2 个主要行动，年底进行年度结算。

季度流程：

1. 查看公司状态。
2. 处理强制事件：现金危机、员工离职、客户投诉、监管问询等。
3. 选择 2 个主要行动。
4. 触发行动结果和随机事件。
5. 更新数值、员工状态、投资人关系。

年度流程：

1. 生成年度财报：现金、ARR、亏损、毛利、runway。
2. 生成组织报告：人数、士气、离职率、关键人才风险。
3. 生成市场报告：竞品、巨头、资本市场、政策环境。
4. 解锁成就。
5. 判断是否触发结局、融资窗口、上市窗口或并购窗口。

## 5. 初始创建

### 5.1 创始人加点

玩家初始有 24 点，可分配到 8 个属性。每个属性范围 1-10，初始最低为 1。

| 属性 | 影响 |
|---|---|
| 技术 | 模型研发效率、技术债控制、技术员工好感 |
| 销售 | 客户获取、ARR 增长、销售团队效率 |
| 融资 | 融资成功率、估值、条款质量 |
| 管理 | 团队规模上限、离职控制、组织混乱概率 |
| 伦理 | 合规事故概率、员工信任、增长捷径限制 |
| 体力 | 可承受高压事件、健康恢复、连续行动惩罚 |
| 忽悠 | PR、发布会、估值叙事、泡沫能力 |
| 运气 | 贵人事件、竞品节奏、监管抽查、事故概率 |

推荐预设：

- 技术信仰型：技术 8，融资 3，销售 3，伦理 6。
- 融资怪物型：融资 8，忽悠 8，技术 3，伦理 2。
- 产业落地型：销售 7，管理 6，技术 4，融资 5。
- 开源理想型：技术 7，伦理 7，销售 2，融资 3。
- 熬夜战神型：体力 9，其他平均，健康下降更慢。

## 6. 核心数据模型

### 6.1 公司指标

所有指标除金额外为 0-100。

| 指标 | 含义 | 低值影响 | 高值影响 |
|---|---|---|---|
| cash | 现金，单位人民币 | 触发裁员、融资打折、并购压价 | 提高安全感，可重投入 |
| runway | 剩余月数 | <6 危险，<3 死亡螺旋 | >18 融资不急 |
| arr | 年经常性收入 | 融资难，估值靠故事 | 解锁增长轮和 IPO |
| mrr | 月经常性收入 | 用于短期增长判断 | 破节点解锁成就 |
| pmf | 产品市场匹配 | 销售越多骂声越多 | ARR 增长更有效 |
| modelPower | 模型能力 | 产品上限低 | 技术叙事、巨头关注 |
| productQuality | 产品质量 | 客诉、流失 | 留存和口碑提高 |
| computeSupply | 算力供给 | 训练停滞、服务降级 | 支持模型突破 |
| computeCost | 算力成本压力 | 毛利下降、现金消耗 | 过高触发黑洞 |
| grossMargin | 毛利率 | 被质疑商业模式 | IPO 和增长轮加分 |
| techDebt | 技术债 | 事故、研发变慢 | 越低越好 |
| reputation | 声望 | 招聘、客户、融资变难 | PR、招聘、融资加成 |
| morale | 士气 | 离职潮 | 组织稳定 |
| complianceRisk | 合规风险 | 调查、下架、IPO 阻断 | 越低越好 |
| globalReadiness | 全球化准备 | 出海失败 | 解锁海外扩张 |
| boardPressure | 董事会压力 | 创始人被踢 | 越低越自由 |
| founderHealth | 创始人健康 | 行动受限、坏结局 | 可连续高压操作 |
| founderEquity | 创始人股权 | 控制权下降 | 越高越稳 |
| valuation | 估值 | 影响融资和结局 | 过高会带来倒挂风险 |
| marketHeat | 资本市场热度 | 融资/IPO 难 | 泡沫和机会并存 |

### 6.2 触发阈值

现金和 runway：

- runway >= 18：融资从容，估值不打折。
- runway 12-18：正常融资窗口。
- runway 6-12：投资人压价，员工开始问期权价值。
- runway 3-6：估值 -25%，并购方出现。
- runway < 3：强制触发裁员、桥接轮、贱卖或死亡结局检查。
- cash < 0：若无紧急融资或并购，进入清算。

ARR：

- ARR = 0：只能靠 Demo、背景和叙事融资。
- ARR >= 100 万：首批付费客户。
- ARR >= 1000 万：A 轮门槛。
- ARR >= 5000 万：B 轮门槛。
- ARR >= 2 亿：C/D 轮门槛。
- ARR >= 5 亿：港股 IPO 准备门槛。
- ARR >= 7 亿且国际收入占比 > 40%：美股 IPO 准备门槛。

PMF：

- pmf < 30：销售动作有 40% 概率变成客诉。
- 30 <= pmf < 50：可拿早期客户，但流失高。
- 50 <= pmf < 70：A 轮及企业客户认可。
- pmf >= 70：增长动作效果 +30%。
- pmf >= 85：解锁“品类定义者”事件。

模型能力：

- modelPower < 30：被市场认为是套壳。
- 30-50：可做垂直应用。
- 50-70：可讲技术壁垒。
- 70-85：巨头开始关注，研究员被挖概率提高。
- >85：触发围剿、收购、监管安全测试。

毛利率：

- grossMargin < 0：卖一单亏一单。
- 0-30：增长投资人质疑商业模型。
- 30-50：可以融资，但 IPO 难。
- 50-70：健康 SaaS/AI 应用。
- >70：现金流公司和 IPO 都加分。

合规风险：

- complianceRisk < 30：低风险。
- 30-50：出海和大客户尽调受影响。
- 50-70：融资条款变差，上市准备受阻。
- 70-85：监管问询、客户暂停采购。
- >85：下架、罚款、诉讼或业务停摆。

士气：

- morale > 70：招聘转介绍、加班负面降低。
- 50-70：稳定。
- 35-50：离职风险上升。
- 20-35：离职潮、匿名吐槽。
- <20：联创出走或核心团队分裂。

创始人股权和控制权：

- founderEquity > 50%：创始人绝对主导。
- 30-50%：正常 VC 公司。
- 20-30%：董事会压力明显。
- 10-20%：有概率被职业 CEO 替换。
- <10%：解锁“打工 CEO”或“被优化的创始人”。

## 7. 行动系统

每季度玩家选择 2 个行动。行动效果受属性、员工、当前状态和随机事件影响。

### 7.1 产品研发

效果：

- productQuality +5 到 +12。
- pmf +2 到 +8。
- techDebt +2 到 +6。
- cash 减少，研发员工疲劳增加。

高风险状态：

- 若 sales 承诺过多，产品研发优先填坑，pmf 增长减半。
- 若 techDebt > 70，有 25% 概率触发线上事故。

### 7.2 模型训练

效果：

- modelPower +3 到 +10。
- computeSupply -5 到 -15。
- computeCost +5 到 +12。
- cash 大幅减少。

触发：

- computeSupply < 20 时，训练有 50% 概率失败。
- modelPower > 75 后，每次训练有概率触发巨头关注或安全质疑。

### 7.3 销售增长

效果：

- ARR 增长。
- 客户数增加。
- sales 团队疲劳增加。

公式：

ARR 增长 = 基础增长 * 销售能力系数 * PMF 系数 * 声望系数 * 市场热度系数。

惩罚：

- pmf < 40 时，销售越猛客诉越多。
- productQuality < 40 时，客户流失率翻倍。

### 7.4 融资路演

效果：

- 打开投资人谈判。
- 消耗创始人健康和时间。
- 提高 boardPressure。

成功率：

融资成功率 = 融资属性 + ARR 分数 + PMF 分数 + 增速分数 + 声望分数 + 市场热度 - runway 惩罚 - 合规惩罚。

条款质量：

- runway 越短，稀释越高。
- complianceRisk 越高，保护条款越多。
- marketHeat 越高，估值越好。
- founderEquity 越低，董事会越强势。

### 7.5 招人

可招聘角色：

- 研究员、工程师、产品经理、销售、算法实习生、法务/合规、财务、HR、PR、COO、CFO、首席科学家、海外 BD、交付经理。

招聘成功率：

招聘成功率 = 声望 + 薪资竞争力 + 期权吸引力 + 赛道热度 + 创始人相关属性 - 公司风险。

### 7.6 留人

操作：

- 加薪：现金消耗增加，忠诚提高。
- refresh 期权：股权池消耗，忠诚提高。
- 升职：忠诚提高，但 title 通胀。
- 放假：疲劳下降，短期产出下降。
- 画饼：短期忠诚提高，若后续融资失败则反噬。
- 组织建设：管理高时有效，管理低时变成团建事故。

### 7.7 合规治理

效果：

- complianceRisk -8 到 -18。
- product release 速度下降。
- cash 减少。

必要性：

- 出海前必须降低合规风险。
- IPO 前必须连续多个季度治理。
- AI 陪伴、教育、医疗、金融赛道合规权重更高。

### 7.8 出海扩张

前置条件：

- ARR >= 5000 万。
- productQuality >= 55。
- globalReadiness >= 50。
- complianceRisk < 50。
- 至少有海外 BD 或区域负责人。

效果：

- 开启海外收入。
- 增加市场上限和估值叙事。
- 提高合规复杂度和管理成本。

### 7.9 PR 发布

效果：

- reputation +5 到 +20。
- marketHeat 小幅上升。
- 若产品/模型指标不足，有概率被群嘲。

典型事件：

- 发布会战神。
- Demo 翻车。
- 被用户发现是人工客服。
- GitHub Star 暴涨但没有收入。

### 7.10 降本增效

操作：

- 裁员。
- 降低训练频率。
- 砍业务线。
- 迁移到低成本模型。
- 砍云厂商账单。

效果：

- runway 增加。
- morale 下降。
- reputation 可能下降。
- 若处理好，grossMargin 提高。

## 8. 员工系统

### 8.1 员工属性

每个员工是角色卡，不只是人数。

字段：

- name：架空姓名。
- role：角色。
- level：Junior/Mid/Senior/Lead/CXO。
- ability：能力 1-100。
- salary：年薪。
- options：期权点数。
- loyalty：忠诚 1-100。
- ambition：野心 1-100。
- fatigue：疲劳 1-100。
- scarcity：稀缺度 1-100。
- departureRisk：离职风险。
- tags：特殊标签。

员工标签：

- 论文脑：模型研发强，商业交付弱。
- 大厂病：流程意识强，早期公司效率低。
- 野生全栈：早期强，规模化后吃力。
- 销售狼：ARR 强，乱承诺风险高。
- 合规洁癖：降风险强，拖慢发布。
- 会议召唤师：管理职位后会议增加。
- 期权信仰者：估值上升时忠诚高，down round 时崩。
- 反骨天才：能力极高，忠诚极低。
- 稳定器：能力普通，能提升团队士气。
- 创业预备役：随时可能离职创业。

### 8.2 员工角色

|---|---|---|
| 研究员 | modelPower 增长 | 被巨头高薪挖，脱离商业 |
| 工程师 | productQuality、techDebt | 疲劳高会事故 |
| 产品经理 | pmf | 过多导致路线图内耗 |
| 销售 | ARR | 乱承诺、回款风险 |

| 法务/合规 | 降 complianceRisk | 拖慢上线 |

| HR | 招聘、士气 | 过早官僚化 |

| COO | 管理规模 | 贵，且会挑战创始人习惯 |
| CFO | 融资、IPO | 没有 CFO 难上市 |

| 海外 BD | 出海 | 费用高，结果慢 |
| 交付经理 | 企业客户留存 | 可能变成定制外包 |

### 8.3 离职和跳槽

基础离职风险：

departureRisk = 市场挖角压力 + 疲劳 + 薪资差距 + 期权水下 + 士气惩罚 + 个人野心 - 忠诚 - 公司声望。

触发条件：

- salary < 市场价 75%：离职风险 +20。
- options 价值低于预期且估值下轮下跌：离职风险 +30。
- morale < 35：全员离职风险 +15。
- fatigue > 80：相关员工离职风险 +20。
- modelPower > 75：研究员被挖风险 +25。
- ARR 增长连续 4 季度低于 5%：销售和高管离职风险 +15。
- founderHealth < 20：CXO 对公司信心下降。

跳槽事件：

- DeepDuck 挖走核心研究员。
- Cloudsoft 挖走企业销售。
- BytePlanet 挖走增长负责人。
- Green Furnace 挖走推理优化工程师。
- 联合创始人离职做垂直 Agent。
- CFO 发现财务太刺激，决定“陪伴到这里”。
- 实习生论文爆火，被所有巨头私信。

反制：

- 加薪：现金下降，忠诚 +15。
- refresh 期权：股权池下降，忠诚 +20。
- 升职：忠诚 +10，管理混乱 +5。
- 绑定关键项目：忠诚 +5，疲劳 +10。
- 放人：短期损失能力，长期士气不降。
- 强硬竞业：短期阻止离职，声望 -10，士气 -10。
- 反挖竞品：招人成功后声望 +5，竞品仇恨 +10。

## 9. 融资系统

### 9.1 融资窗口

融资不是每年固定触发，而是由窗口决定。

融资窗口打开条件：

- runway < 18。
- ARR 达到阶段门槛。
- modelPower 突破阶段门槛。
- 竞品大融资带动赛道热。
- 巨头发布相近产品，战投或并购方关注。
- 出海市场拿到关键客户。
- 资本市场热度 > 60。

融资窗口关闭条件：

- runway < 3 且没有强叙事。
- complianceRisk > 75。
- 毛利率 < 0 且 ARR 增长不够快。
- 核心团队离职。
- 大客户流失。
- 市场热度 < 30。

### 9.3 条款系统

投资不只是钱。每张 term sheet 包含：

- 投资金额。
- 投前估值。
- 稀释比例。
- 清算优先权。
- 董事会席位。
- 反稀释条款。
- 创始人 vesting。
- 排他合作。
- 云资源绑定。
- 数据/生态接入要求。
- 回购或业绩对赌。

条款等级：

- 友好条款：稀释少，无排他，无强清算优先。
- 正常条款：1x 清算优先，1 个董事席位。
- 压力条款：高稀释、反稀释、信息权、预算否决权。
- 魔鬼条款：回购、对赌、强制出售权、创始人 vesting 重置。

触发：

- runway < 6：条款等级至少正常。
- runway < 3：条款等级偏压力或魔鬼。
- marketHeat > 75：条款改善。
- founderEquity < 20：董事会要求更多控制。
- complianceRisk > 60：投资人要求保护条款。

## 13. 上市与退出

### 13.1 港股 IPO

游戏条件：

- ARR >= 5 亿人民币。
- grossMargin >= 45。
- complianceRisk < 40。
- CFO 在岗至少 4 个季度。
- 审计准备 >= 70。
- 董事会治理 >= 60。
- 最近 8 个季度无重大合规事故。

优势：

- 中国/亚洲业务更容易讲清楚。
- 政企和产业客户更友好。
- 对全球收入占比要求低。

风险：

- 估值可能低于美股。
- 若增长放缓，破发概率高。

### 13.2 美股 IPO

游戏条件：

- ARR >= 7 亿人民币。
- 国际收入占比 >= 40%。
- ARR 年增速 >= 50%。
- grossMargin >= 55。
- complianceRisk < 35。
- CFO 和投行关系成熟。
- 美元基金或全球投资人支持。

优势：

- 估值叙事更强。
- 全球投资人接受度高。

风险：

- 合规和披露压力高。
- 地缘和数据审查风险。
- 上市窗口依赖市场热度。

### 13.3 并购

并购触发：

- runway < 6。
- 巨头好感 > 60。
- modelPower > 70 或 ARR > 1 亿。
- 创始人健康低或董事会压力高。

并购结局变量：

- 价格：ARR 倍数、模型能力、竞购数量。
- 创始人锁定期：2-4 年。
- 产品命运：独立运营、整合、关闭。
- 员工保留率。

### 13.4 现金流公司

触发条件：

- ARR >= 1 亿。
- grossMargin >= 60。
- 增速不一定高，但 runway > 24。
- founderEquity >= 35。
- boardPressure < 50。

结果：

- 不一定敲钟，但创始人自由度高。
- 解锁“睡得着的老板”结局。

2. 云券富翁：云券价值 > 现金 5 倍。
3. 员工比用户多：员工数 > 活跃付费客户数。
4. 会议驱动开发：连续 4 季度没有产品增长但管理动作很多。
5. 发布会战神：reputation > 80 但 retention < 30。
6. 合规即服务：主营失败后转型合规咨询。
7. 估值和睡眠不可兼得：valuation > 70 亿且 founderHealth < 10。
8. 董事会养成游戏：董事席位 > CXO 人数。
9. 大客户定制仙人：ARR 高但 productQuality 下降。
10. 先融资后想商业模式：完成 B 轮时 ARR < 1000 万。
11. 朋友圈治公司：用 PR 行动解决董事会事件。
12. 赛博修仙：连续 8 季度 founderHealth < 20 但公司未死。
13. 一夜变插件：被巨头生态集成后独立品牌消失。
14. 周报上市：IPO 准备期间每季度报告超过产品发布。
15. 开源背刺亲历者：被 DeepDuck 事件估值腰斩。
16. GPU 乞丐：连续 4 季度 computeSupply < 20。

### 15.4 阴间成就

1. 被优化的创始人：公司存活但创始人离任 CEO。
2. 期权废纸化：估值低于上一轮且员工大量离职。
3. 算力黑洞：computeCost > ARR。
4. 数据坟场：数据合规事故导致业务停摆。
5. 上市即破发：IPO 后首日破发。
6. 体面失败：清算时工资和供应商全部结清。
7. 不体面失败：清算后仍有欠款。
8. 核心团队出走：3 名以上核心员工同年离职。
9. 大客户勒索：单一客户收入占比 > 70%。
10. 监管叫停：complianceRisk > 90。
11. 创始人健康归零：健康为 0。
12. 自己收购自己：创始人离开后另起炉灶买回旧业务。

## 16. 结局系统

结局在第 12 年或提前触发。优先级：死亡结局 > 强制退出 > 成功结局 > 普通结局。

### 16.1 顶级成功

1. 美股敲钟，硅谷封神  
条件：美股 IPO 成功，市值高，founderEquity > 12，reputation > 75。

2. 港股 AI 第一股  
条件：港股 IPO 成功，亚洲收入强，合规低。

3. 全球 AI 基础设施  
条件：ARR > 20 亿，grossMargin > 60，国际收入 > 50，modelPower 或 productQuality > 85。

4. 开源教父  
条件：开源声望 > 90，社区规模极高，现金流未死。

5. 现金流小巨人  
条件：ARR > 3 亿，runway > 36，founderEquity > 35，不上市。

### 16.2 普通成功

6. 巨头并购，财务自由  
条件：并购价格高，创始人套现，产品部分保留。

7. 行业龙头  
条件：垂直赛道占有率高，ARR > 5 亿。

8. 区域王者  
条件：海外单一区域成功，整体未 IPO。

9. 政企隐形冠军  
条件：政企收入高，增速一般但稳定。

10. 大厂插件王  
条件：被 Cloudsoft/Tencentacle/BytePlanet 深度集成，收入稳定但品牌弱。

### 16.3 半成功

11. 纸面首富  
条件：估值高但未退出，现金流紧张。

12. 上市破发但还活着  
条件：IPO 成功但市场热度低或增长放缓。

13. 创始人被踢，公司成功  
条件：CEO 离任，公司 IPO 或并购。

14. 卖早了  
条件：早期并购，之后行业爆发。

15. 转型咨询公司  
条件：产品失败但销售/交付强。

16. 只在投资人 PPT 里伟大  
条件：估值高，ARR 低，最终被低价收购。

17. 科研机构化  
条件：技术强，商业弱，靠项目和补贴活着。

18. 生活方式公司  
条件：规模不大但盈利，创始人健康高。

### 16.4 失败

19. 现金流断裂  
条件：cash < 0，无融资无并购。

20. 算力债务压垮  
条件：computeCost 长期高于收入且无毛利改善。

21. 监管暴雷  
条件：complianceRisk > 90 且触发重大事故。

22. 版权诉讼地狱  
条件：内容/搜索/陪伴赛道，合规低，声望高。

23. 核心团队出走  
条件：士气低，核心员工大量离职。

24. 被开源打穿  
条件：闭源模型护城河低，DeepDuck 多次冲击。

25. 被巨头免费功能碾死  
条件：产品型赛道，巨头复制，pmf 不够强。

26. 创始人健康崩溃  
条件：founderHealth = 0。

27. 员工解散，公众号复盘  
条件：清算后 reputation 还可以。

28. 不体面清算  
条件：欠薪、欠供应商、声望低。

### 16.5 特殊结局

29. 进厂重开  
条件：公司失败，技术属性高，声望未归零。

30. 投资人转型创业导师  
条件：失败后融资属性高，写复盘爆火。

31. AI 风水大师  
条件：家族办公室事件链完成且主营偏离。

32. 园区永久荣誉顾问  
条件：产业基金路线失败但材料完成度极高。

33. 二次创业又来了  
条件：失败但保留核心团队和声望。

34. 被前员工收购  
条件：创始人被踢，前员工创业成功。

35. 模型没有 AGI，你先悟了  
条件：开源/伦理高，主动缩小公司。

36. 股价涨了，产品没了  
条件：上市或并购后产品被砍，但资本回报高。

## 17. 数据公式草案

### 17.1 Runway

monthlyBurn = salaryCost + computeCostCash + officeCost + salesCost + complianceCost - monthlyRevenueCash

runway = cash / max(monthlyBurn, 1)

若 monthlyBurn <= 0，则 runway 显示为 36+，并标记为现金流为正。

### 17.2 估值

基础估值：

valuation = ARR * revenueMultiple + technologyPremium + strategicPremium + marketHeatPremium - riskDiscount

revenueMultiple：

- AI 应用：4x-12x ARR。
- 高增长 AI SaaS：8x-20x ARR。
- 模型平台：可按收入倍数 + 技术溢价。
- 无收入早期：按团队、Demo、市场热度估值。

风险折扣：

- runway < 6：-25%。
- complianceRisk > 60：-20%。
- grossMargin < 20：-15%。
- 核心员工离职：-10%。
- down round 后：投资人信心 -20。

### 17.3 ARR 增长

ARR 增长率 = baseGrowth + pmfFactor + salesFactor + reputationFactor + marketFactor + productFactor - churnFactor - complianceDrag

关键影响：

- pmf < 40 时，salesFactor 上限受限。
- productQuality < 40 时，churnFactor 大幅提高。
- grossMargin < 0 时，增长越快现金越危险。

### 17.4 员工离职风险

departureRisk = 20 + fatigue/3 + salaryGap + underwaterOptions + moralePenalty + ambition/4 + poachingPressure - loyalty/2 - reputation/5

若 departureRisk > 70，季度末触发离职谈判。

### 17.5 融资成功率

fundraisingScore = founderFundraising * 6 + ARRScore + growthScore + PMFScore + marketHeat + reputation/2 + investorFit - compliancePenalty - runwayPenalty - chaosPenalty

结果：

- >= 85：多张 term sheet。
- 70-84：融资成功，条款正常。
- 55-69：融资成功但条款差。
- 40-54：可能拿桥接轮或战投。
- <40：融资失败。

## 18. UI 草案

主界面不做营销页，直接进入游戏。

页面结构：

- 顶部：年份、季度、现金、runway、ARR、估值。
- 左侧：行动面板。
- 中央：事件和决策。
- 右侧：公司仪表盘、员工风险、投资人关系。
- 底部：日志、成就、年度报告入口。

核心页面：

1. 创建创始人。
2. 选择出身和赛道。
3. 季度经营页面。
4. 员工管理页面。
5. 融资谈判页面。
6. 出海地图页面。
7. 年度报告页面。
8. 成就墙。
9. 结局复盘。

视觉风格：

- 黑色幽默商业模拟器。
- 类终端 + 投资人 deck + 经营仪表盘混合。
- 不做可爱卡通，不做手游抽卡风。
- 卡片克制，信息密度较高。
- 颜色：深色底，现金/风险/增长用清晰状态色，但避免全紫全蓝。

## 20. 验证点

设计自检：

- 每个核心结果都有数据触发，不依赖纯随机。
- 黑色幽默来自系统性矛盾：增长 vs 毛利、融资 vs 控制权、技术 vs 商业、出海 vs 合规。
- 中国起步和全球扩张都在规则里体现。
- 员工有可操作空间，不只是数值加成。
- 融资条款有代价，不只是送钱。
- 上市不是固定年份，而是条件窗口。
- 巨头影射架空化，避免直接使用真实商标和人物。
